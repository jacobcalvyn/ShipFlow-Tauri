## 6. Key Technical Decisions

1. Use one textarea for many Bag/Manifest IDs.
   - Splits by whitespace/comma/semicolon; dedupes while preserving order.

2. Use bounded parallel import workers.
   - Source lookups and manifest-derived Bag lookups both use fixed concurrency of 4.

3. Model partial success explicitly.
   - Source Bag/Manifest IDs live in `sourceItemStates`; manifest-derived Bag IDs live in `manifestBagStates`.

4. Retry only explicit failed targets.
   - Targeted failed items become loading; successful state is preserved; new tracking IDs merge with dedupe.

5. Preserve dotted IDs but lookup details with base ID.
   - `P2606020189412.30` remains the displayed/imported value.
   - Detail lookup uses `P2606020189412`.
   - This assumes dot-number suffixes are Bag/Manifest sub-item suffixes, not separate upstream tracking IDs.
